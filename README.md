# Recipe Planner

A simple weekly meal planner for organizing recipes, scheduling meals, and building a grocery list.

## Features

- Save and edit recipes
- Search by recipe name, tag, or ingredient
- Schedule meals for each day of the week
- View an aggregated grocery list
- Persistence using browser localStorage

## Run locally

From the project root:

```bash
python -m http.server 8000
```

Then open http://localhost:8000 in your browser.
